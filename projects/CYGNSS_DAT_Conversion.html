Converting DAT Files to CSV

This guide outlines how to use datcon on macOS to convert CYGNSS drone .DAT telemetry files into easy-to-use .CSV files.

  1. Install Java if it is not already available on your Mac.
  2. Download the latest datcon release and unzip it.
  3. Open Terminal and run java -jar DatCon.4.3.0.jar.
  4. The tool will create a folder with the resulting CSV files for further analysis.

Once you have a CSV file, you can explore the drone's flight data using the CSV Data Visualizer.
